# fslSybil-data: simulation dataset for few-shot Sybil attack detection in the IoV

This repository contains **only the data** generated for the study
"Few-Shot Learning for Adaptive Sybil Attack Detection in the Internet of Vehicles"
(R. Kumar, C. Mandal and A. R. K. P). It holds no code. The simulation modules
and the training and evaluation scripts are in the companion repository
[bashkid/fslSybil](https://github.com/bashkid/fslSybil).

The data were generated by an OMNeT++ 6.1 / Veins / INET 4.5 and SUMO 1.20.0
co-simulation of IEEE 802.11p Basic Safety Messages (BSMs) on the real road
network of Indiranagar, Bengaluru (India), with three Sybil attack variants:
random position fabrication (SA-RND), trajectory fabrication (SA-TRJ) and
coordinated attacks (SA-CRD).

## Contents

| Folder | Contents |
|---|---|
| `raw/sybil_data/` | Per-node output of scenarios **S1–S10** (the dataset used in the paper): `raw_bsm_S<id>_node<n>.csv` (received BSMs) and `features_S<id>_node<n>.csv` (windowed features), 2,970 files |
| `raw/sybil_data_realistic/` | The same for a later re-run, scenarios **RS1–RS10** (not used in the paper), 2,970 files |
| `raw/omnet_scalar_results/` | OMNeT++ scalar results (`.sca`) of every run, one `xz` archive per scenario, with SHA-256 checksums |
| `processed/paper/` | Merged dataset of S1–S10 (`merged_features.csv`, 65,087 samples), `dataset_stats.txt`, and the splits in `splits/` |
| `processed/realistic/` | The same for RS1–RS10 (65,398 samples) |

### Features and labels

Each feature row describes one (observer, observed) vehicle pair over a 5-second
sliding window with a 2.5-second stride. There are 20 features:

- **BSM (10):** `msg_frequency`, `pos_x_mean`, `pos_y_mean`, `speed_mean`, `speed_var`, `heading_mean`, `heading_change_rate`, `accel_mean`, `accel_var`, `brake_ratio`
- **Mobility (6):** `distance_traveled`, `pos_jump_count`, `max_pos_jump`, `speed_pos_consistency`, `traj_smoothness`, `neighbor_count`
- **Network (4):** `rssi_mean`, `rssi_consistency`, `timestamp_regularity`, `sender_recv_dist_consistency`

Labels: `is_sybil` (0 = legitimate, 1 = Sybil) and `attack_type`
(0 = legitimate, 1 = SA-RND, 2 = SA-TRJ, 3 = SA-CRD). The processed files
also carry `sim_time`, `observer_id`, `observed_id` and `scenario_id`.

### Paper dataset (`processed/paper/`)

- 65,087 samples: 49,563 legitimate (76.1 %) and 15,524 Sybil (23.9 %), of which 1,315 SA-RND, 1,299 SA-TRJ and 12,910 SA-CRD.
- Splits, stratified by attack type and label: `train.csv` (65 %, 42,306), `val.csv` (15 %, 9,763) and `test.csv` (20 %, 13,018).
- `cross_scenario_train.csv` (S1–S7) / `cross_scenario_test.csv` (S8–S10) hold a split by scenario.
- The split CSVs contain the raw (unscaled) feature values.

### Notes

- For S1–S10, only the scalar file of repetition 0 was kept; RS1–RS10 have all five repetitions. The per-node feature files are complete for every scenario.
- OMNeT++ vector results (`.vec`) were not kept.
- Extract and verify the scalar results:
  `mkdir -p sca && for a in raw/omnet_scalar_results/*.tar.xz; do tar -xJf "$a" -C sca; done`, then
  `cd sca && shasum -a 256 -c ../raw/omnet_scalar_results/SHA256SUMS_sca.txt`.
